# Mahan OTP Relay for Android — 2.8.0

یک اپ اندروید اختصاصی و شفاف برای اتصال پایدار گوشی به `https://otp.mahanvip.ir` و تحویل OTP به MahanBot.

## رفتار نسخه 2.8.0

- سرور در کد ثابت است و فیلد کلید یا نشانی دستی ندارد.
- کاربر برای سیم‌کارت ۱ و ۲ کد ملی جداگانه تعریف می‌کند.
- فقط پیامکی که عبارت تنظیم‌شده را داشته باشد و شامل OTP چهار تا هشت رقمی باشد پردازش می‌شود.
- سرویس Foreground با اعلان دائمی هر ۲۰ ثانیه وضعیت سرور را بررسی می‌کند.
- پیامک دریافت‌شده ابتدا در صف محلی ذخیره و سپس با retry محدود ارسال می‌شود.
- سرویس پس از Boot و به‌روزرسانی اپ بازیابی می‌شود.
- اپ کل متن پیامک را ذخیره نمی‌کند؛ فقط OTP، کد ملی، شناسه پیام و زمان دریافت در صف کوتاه‌مدت نگهداری می‌شود.
- کلید داخلی Bot به Relay همچنان فقط سمت سرور باقی می‌ماند؛ گوشی هیچ کلید دستی ندارد.

## ساخت محلی

```bash
gradle :app:testDebugUnitTest :app:assembleDebug
```

APK محلی در مسیر زیر ساخته می‌شود:

```text
app/build/outputs/apk/debug/app-debug.apk
```

## ساخت در GitHub Actions

Workflow با هر تغییر در این پروژه، تست‌ها را اجرا و APK را با نام Artifact زیر منتشر می‌کند:

```text
MahanOtpRelay-2.8.0-apk
```
