# مرز فریز بخش کپچا

این شاخه از نسخه قبلی پروژه ساخته شده است تا منطق موجود کپچا بدون بازنویسی باقی بماند و سایر بخش‌های MahanBot مستقل ارتقا پیدا کنند.

## فایل‌های فریز‌شده

- `captcha_service.py`
- `my_captcha_model.pth`

شناسه Git Blob مورد انتظار:

```text
captcha_service.py: 60b4672b53ab4f07d69b86541ce29a0df01f8788
my_captcha_model.pth: 57a2f6fe7bc48036e765706ba8f081cfbbf36f62
```

## قانون توسعه

در فازهای ارتقای فرانت، دیتابیس، پیامک، لاگ، پایداری، نصب Windows و کارایی، فایل‌های بالا تغییر نمی‌کنند. همچنین رفتار فراخوانی فعلی کپچا بازطراحی یا جایگزین نمی‌شود.

هر تغییری در این مرز باید خارج از جریان ارتقاهای عمومی و توسط مالک پروژه انجام شود.

## بخش‌های مجاز برای ارتقا

- رابط کاربری و دسترس‌پذیری داشبورد
- دیتابیس و مهاجرت امن
- اتصال و وضعیت پیامک
- WebSocket و مدیریت Job
- سرعت، مصرف حافظه و لاگ‌ها
- نصب و اجرای یک‌کلیکی Windows Server
- پشتیبان‌گیری، بازیابی و Rollback
- مانیتورینگ و گزارش خطا
