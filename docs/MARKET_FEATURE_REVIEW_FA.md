# بررسی ویژگی‌های عمومی بازار

منابع تلگرامی اعلام‌شده صرفاً به‌عنوان صفحات عمومی/تبلیغاتی در نظر گرفته شدند. هیچ کانال
خصوصی، فایل، APK یا کد محصول ثالث استفاده نشده است و ادعاهای غیرقابل مشاهده، قابلیت فنی
اثبات‌شده محسوب نمی‌شوند.

| ویژگی | تصمیم | پیاده‌سازی مستقل امن |
|---|---|---|
| چند متقاضی | پذیرش کنترل‌شده | صف محدود، Job/Context/Session جدا، concurrency پیش‌فرض ۲ |
| بانک‌های موجود و علاقه‌مندی | پذیرش | snapshot نتیجه و اعلان opt-in با backoff |
| اعلان بانک مطلوب | پذیرش | اعلان رویدادمحور؛ بدون polling یک‌ثانیه‌ای |
| بازیابی تغییر سایت | پذیرش | contract fixture و selector fallback |
| OTP از Android | پذیرش | Consent API یا RECEIVE_SMS فقط در private |
| OTP از Web | فقط دستی | session-bound، idempotent و audit ماسک‌شده |
| وضعیت دستگاه | پذیرش | health تازه‌تر از ۶۵ ثانیه |
| کد رهگیری/آرشیو | پذیرش | داده نتیجه، بدون OTP یا secret |
| update/backup | پذیرش | artifact امضاشده و backup رمزگذاری‌شده |
| امنیت و رضایت | الزام | pairing یک‌بارمصرف، token hash، consent versioned |
| auto-submit نهایی | رد | `final_submit=false` و اجازه صریح کاربر |
| خواندن Inbox/تاریخچه | رد | بیش‌ازحد و ناسازگار با رضایت |
| stealth/fingerprint spoofing | رد | پرخطر و ناپایدار |
| heartbeat دائم/FGS مخفی | رد | ناسازگار با Android 15 و مصرف منابع |

ظاهر یا کد هیچ محصولی تقلید نشده است. معیار قابلیت قابل‌اثبات، تست repository و قرارداد API
است؛ نه متن تبلیغاتی.
