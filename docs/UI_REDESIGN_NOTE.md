# بازطراحی رابط MahanBot

## هدف

این نسخه رابط قدیمی را بدون تغییر شناسه‌های فرم و منطق عملیات بازطراحی می‌کند. لایه جدید از طریق `ui_v2.py` به صفحه اصلی تزریق می‌شود؛ بنابراین Rollback ساده است و فایل اصلی `static/index.html` دست‌نخورده باقی می‌ماند.

## تغییرات ظاهری

- طراحی یکپارچه آبی، فیروزه‌ای، نیلی، طلایی و نارنجی
- سایدبار حرفه‌ای و منوی موبایل
- کارت‌های آماری سبک‌تر
- فرم‌ها، جداول، وضعیت‌ها و دکمه‌های یکدست
- ترمینال خواناتر با محدودیت تعداد ردیف‌های DOM
- نمایش بهتر اعلان اتصال پیامک
- ترجمه عنوان‌های انگلیسی باقی‌مانده
- پشتیبانی بهتر از موبایل و نمایشگرهای کوچک
- رعایت `prefers-reduced-motion`

## بهینه‌سازی سرعت

- حذف درخواست فونت خارجی Vazirmatn و استفاده از فونت سیستم
- حذف افکت‌های سنگین و انیمیشن‌های دائمی
- محدودسازی DOM لاگ‌ها به ۳۲۰ ردیف
- توقف Polling هنگام مخفی‌شدن تب
- خاموش‌کردن Access Logهای Uvicorn در اجرای عادی
- استفاده از WebSocket به‌عنوان مسیر اصلی و Polling فقط در قطع ارتباط

## حذف Health Check

صفحه `static/healthcheck.html` حذف شده است. در اجرای یکپارچه، ارجاع‌های قدیمی `open_healthcheck_page` به تابع بدون عملیات تبدیل می‌شوند؛ بنابراین مرورگر مستقیماً به صفحه هدف می‌رود و هیچ صفحه داخلی یا انتظار اضافی اجرا نمی‌شود.

## Rollback

برای بازگشت رابط کافی است `install_ui_v2` از `unified_server.py` حذف شود. منطق اصلی داشبورد و عملیات در فایل‌های قدیمی حفظ شده است.
