## ۱. ویژگی‌ها و قابلیت‌های کلیدی

### مدیریت مرکزی لایسنس

در منوی «لایسنس ماهان»، نسخه مدیر می‌تواند لایسنس مشتری صادر، تمدید و غیرفعال و ظرفیت دستگاه را مدیریت کند. نسخه مشتری به سرور اختصاصی `otp.mahanvip.ir` متصل است. [راهنمای مشتری](LICENSE_CLIENT_FA.md) و [گزارش پیاده‌سازی و آزمون واقعی](LICENSE_INTEGRATION_REPORT_FA.md) جزئیات را توضیح می‌دهند.

### ۱. پایش مداوم ظرفیت در صفحه سوم (Page 3 Quota Sniping)
- **عدم بازگشت به صفحه اول:** در صورت پر بودن ظرفیت یا تغییرات موقت، صفحه سوم و نشست مرورگر کاملاً زنده نگه داشته می‌شوند و سامانه به صفحه اول بازنمی‌گردد.
- **تلاش هوشمند دوره‌ای:** بررسی مجدد سهمیه با کلیک روی دکمه ثبت فرم در فواصل زمانی تنظیمی (۵ الی ۲۰ ثانیه).
- **تشخیص دقیق پاسخ سرور:** تفکیک قطعی میان «تکمیل ظرفیت»، «رزرو بدون شعبه»، «خطای ناوبری» و «ثبت قطعی سهمیه» از روی پاسخ‌های زنده ASP.NET و تغییرات DOM.

### ۲. موتور تطبیق بانک و دیتابیس رابطه‌ای یکپارچه
- پایگاه داده رابطه‌ای SQLite با ساختار تفکیک‌شده برای ۳۱ استان رسمی، ۵۴ شهر، ۳۰ بانک رسمی و شعب.
- **تطبیق بر اساس نام استاندارد:** شناسایی بانک بر مبنای متن دراپ‌داون در DOM زنده بدون وابستگی به مقادیر عددی ناپایدار `value`.
- پشتیبانی کامل از موارد خاص جغرافیایی (نظیر «چابهار مناطق آزاد» در برابر «چابهار سیستان»، و نگاشت اسامی تاریخی مانند «مهرستان / زابلی»).
- ۴ روش پذیرش قابل تنظیم: فقط غیرحضوری (`only_online`)، اولویت با غیرحضوری (`prefer_online`)، اولویت با حضوری (`prefer_in_person`)، فقط حضوری (`only_in_person`).

### ۳. مدیریت صف موازی و استقلال متقاضیان
- اجرای هم‌زمان متقاضیان در رزوه‌های مستقل با محدودیت بهینه هم‌روندی (`MAHANBOT_MAX_CONCURRENCY`).
- انتظار یا تأخیر یک متقاضی برای دریافت کد پیامک یا باز شدن ظرفیت، هیچ‌گونه مانعی برای اجرای سایر متقاضیان ایجاد نمی‌کند.
- قفل اتمیک ثبت نهایی (`claim_final_submission`) برای جلوگیری قطعی از ارسال مجدد یا ثبت تصادفی چندباره.

### ۴. حل ۱۰۰٪ آفلاین و محلی کپچا (Offline CRNN)
- مدل هوش مصنوعی محلی PyTorch (`my_captcha_model.pth`) با معماری CRNN که پیش از شروع در RAM گرم می‌شود (Pre-warmed).
- حل کپچا در کمتر از ۲۰۰ میلی‌ثانیه بدون ارسال هیچ‌گونه بایت تصویر به اینترنت یا سرورهای خارجی.

### ۵. نمای متمرکز و بهینه‌سازی پنجره مرورگر (Focus View)
- ابعاد جمع‌وجور پنجره مرورگر (`540×680` یا `620×730`) متناسب با مانیتورهای مختلف.
- بزرگ‌نمایی قابل تنظیم (پیش‌فرض ۱۲۵٪) و حذف بخش‌های اضافه قالب صفحه جهت خوانایی کامل فرم ثبت‌نام.

## ۳. راهنمای نصب سریع در ویندوز (۱-کلیک)

### الف) روش خودکار:
کافی است روی فایل زیر دو بار کلیک کنید:
```bat
install.bat
```
این اسکریپت به‌صورت خودکار:
1. محیط مجازی مجزای `.venv` را ایجاد می‌کند.
2. پکیج‌های پایتون را مطابق `requirements.txt` نصب می‌کند.
3. باینری مرورگر Chromium را بارگذاری می‌کند.
4. فایل تنظیمات `.env` و پایگاه داده خام و تمیز `cbi_ultimate.db` را آماده‌سازی می‌نماید.

### ب) روش دستی (فرمان متنی):
```powershell
# ۱. ایجاد و فعال‌سازی محیط مجازی
python -m venv .venv
.\.venv\Scripts\Activate.ps1

# ۲. نصب وابستگی‌ها و مرورگر
pip install -r requirements.txt
playwright install chromium

# ۳. آماده‌سازی تنظیمات
cp .env.example .env
python scripts\create_clean_distribution_db.py cbi_ultimate.db
```

## ۴. اجرای برنامه و داشبورد مدیریت

برای شروع ربات:
```bat
start.bat
```
سپس مرورگر شما به‌صورت خودکار باز شده و داشبورد در آدرس زیر در دسترس قرار می‌گیرد:
```text
http://127.0.0.1:8000
```

> **نکته امنیتی:** در اولین راه‌اندازی برای نصب جدید، مشخصات مدیر اولیه در فایل `.env` را بررسی کنید:
> ```ini
> MAHANBOT_ADMIN_USER=admin
> MAHANBOT_ADMIN_PASSWORD=رمز_عبور_دلخواه
> ```

## ۶. دریافت خودکار کد پیامک (OTP)

سیستم به سه شیوه منعطف کدهای پیامکی ورود را دریافت می‌کند:
1. **ورود مستقیم از طریق مرورگر یا پنل:** کاربر یا اپراتور می‌تواند کد پیامک را مستقیماً در فیلد باز مرورگر یا از طریق کارت متقاضی در پنل وارد کند.
2. **وب‌هوک سرور اصلی:** اپلیکیشن اندروید فورواردر می‌تواند پیامک‌ها را به آدرس `http://<SERVER_IP>:8000/receive_sms` یا `/sms/webhook` ارسال نماید.
3. **ریلی مستقل (`otp_server.py`):** با اجرای اسکریپت `start_otp_server.bat` سرویس ریلی روی پورت ۸۰۱۰ آغاز به کار می‌کند.

## ۷. مدیریت و سلامت پایگاه داده

- **تهیه نسخه پشتیبان با ۱ کلیک:** با کلیک روی فایل `backup_database.bat` یا استفاده از دکمه «تهیه پشتیبان» در داشبورد، یک کپی امن از پایگاه داده در پوشه `backups/` ذخیره می‌شود.
