# Mahan Bot — نسخه اصلاح‌شده

این نسخه مسیر «انتخاب بانک» را سریع‌تر و پایدارتر می‌کند، جلوی اجرای هم‌زمان تکراری را می‌گیرد، در صورت بسته‌شدن ناگهانی مرورگر آن را دوباره باز می‌کند و وضعیت اجرای هر متقاضی را در داشبورد نشان می‌دهد.

## نصب

```powershell
cd "C:\Users\amir\Desktop\Mahanbot-fixed-20260808"
py -3.12 -m pip install -r requirements.txt
py -3.12 -m playwright install chromium
```

در پایگاه داده موجود، کاربران قبلی بدون تغییر حفظ شده‌اند. فقط برای یک نصب کاملاً تازه که هنوز هیچ کاربری ندارد، پیش از اولین اجرا رمز مدیر را تعیین کنید:

```powershell
$env:MAHANBOT_ADMIN_USER = "admin"
$env:MAHANBOT_ADMIN_PASSWORD = "یک-رمز-قوی-و-جدید"
py -3.12 server.py
```

سپس `http://127.0.0.1:8001` را باز کنید. پورت با `MAHANBOT_PORT` قابل تغییر است. اگر پورت اشغال بود، ابتدا پردازش مالک را بررسی کنید:

```powershell
Get-NetTCPConnection -LocalPort 8001 -State Listen | Select-Object OwningProcess
```

## رفتار کپچا

کپچا به‌طور کامل روی همین سیستم و با مدل PyTorch حل می‌شود؛ تصویر کپچا به هیچ API خارجی ارسال نمی‌شود. مسیر پیش‌فرض مدل `my_captcha_model.pth` در پوشه پروژه است. برای استفاده از مدل دیگری، متغیر محیطی زیر را پیش از اجرای سرور تنظیم کنید:

```powershell
$env:CAPTCHA_MODEL_PATH = "C:\models\my_captcha_model.pth"
```

ربات از المان کپچا یک تصویر موقت می‌گیرد، آن را با PIL پیش‌پردازش می‌کند، پاسخ مدل را پس از اعتبارسنجی در فیلد وارد می‌کند و فایل موقت را در همه حالت‌ها حذف می‌کند.

## آزمون‌ها

```powershell

```

برای آزمون زنده چرخه انتخاب بانک:


جزئیات تغییرات و نتایج اندازه‌گیری در `FIX_REPORT.md` ثبت شده است.

## رد درخواست و نشست مرورگر

صفحه `Request Rejected` یک چالش قابل حل با کپچا نیست. بات آن را با وضعیت `SITE_REJECTED` متوقف می‌کند و شناسه پشتیبانی، کد HTTP و مسیر ناوبری را بدون Cookie، Header یا داده فرم ثبت می‌کند. چالش امنیتی دارای ورودی `#ans` باید توسط کاربر در مرورگر تکمیل شود؛ مدل کپچا برای فایروال اجرا نمی‌شود.

برای بررسی یک درخواست بدون ارسال فرم:

```powershell
py -3.12 scripts\diagnose_navigation.py --output diagnostics\automatic.json
py -3.12 scripts\diagnose_navigation.py --manual --output diagnostics\manual.json
```

هر دو آزمون مرورگری با نشست تازه و بدون پروکسی باز می‌کنند. در آزمون دستی، آدرس را خودتان وارد کنید و سپس در ترمینال Enter بزنید. این مقایسه اثر نحوه ناوبری را بررسی می‌کند؛ برای مقایسه با مرورگر روزمره باید شرایط شبکه و نشست آن نیز بررسی شوند. فایل HAR خام ممکن است اطلاعات ورود داشته باشد؛ منتشر نکنید.

نشست پایدار، وقتی `clear_cookies=false` است، از `chrome_profiles` استفاده می‌کند. مسیر مجاز با `MAHANBOT_PROFILE_ROOT` قابل تنظیم است؛ پوشه پروفایل مرورگر روزمره را هم‌زمان با بات باز نکنید.
